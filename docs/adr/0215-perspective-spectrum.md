# ADR-0215: Value-Driven Perspective Spectrum (CAP-103)

## Status

ACCEPTED

## Context

Dilemma choices emerge from deep-seated underlying human values (such as Security, Autonomy, Equality, Tradition, Innovation) rather than arbitrary whims. Under `KEFE-PB-001`, `KEFE-ETG-001`, and `KEFE-ENG-001`, KEFE provides a Perspective Spectrum visualization mapping arguments and consensus nodes across a multi-hue value spectrum to foster empathy and mutual understanding across worldview divides.

## Decision

1. **Primary Value Hue Model**:
   - `SECURITY_AND_ORDER`: Cyan-blue hue.
   - `AUTONOMY_AND_LIBERTY`: Amber/gold hue.
   - `EQUALITY_AND_CARE`: Coral/empathy hue.
   - `INNOVATION_AND_PROGRESS`: Emerald/teal hue.
   - `TRADITION_AND_HERITAGE`: Burgundy/slate hue.
2. **Distribution Invariant**:
   - Primary values describe argument foundations only; never individual user psychological classifications.

## Consequences

- Humanizes opposed viewpoints by connecting them to valid underlying moral intuitions.
- Promotes constructive bridge-building over tribal demonization.
