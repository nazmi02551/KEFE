# ADR-0229: Adaptive Cognitive Load & Information Density (CAP-083)

## Status

ACCEPTED

## Context

Complex policy dilemmas can overwhelm everyday citizens with excessive statistical data, while researchers and jurists require high-density analytical graphs. Under `KEFE-PB-001`, `KEFE-ETG-001`, and `KEFE-ENG-001`, KEFE provides an Adaptive Cognitive Load engine offering dynamic view density modes that prevent decision fatigue without concealing critical trade-offs.

## Decision

1. **Cognitive Density Mode Taxonomy**:
   - `STREAMLINED_ESSENTIALS`: Core dilemmas, key principles, and simple trade-off sliders.
   - `BALANCED_DELIBERATIVE`: Standard perspective breakdown, stakeholder impacts, and evidence snippets.
   - `SCHOLARLY_EXHAUSTIVE`: Full mathematical vector spaces, regression residuals, and comprehensive citations.
2. **Parity Invariant**:
   - Switching to `STREAMLINED_ESSENTIALS` must never filter out counter-arguments or compromise blind-first rigor.

## Consequences

- Prevents cognitive overload and decision fatigue across all user demographics.
- Retains full analytical depth for policy researchers.
